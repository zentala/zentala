## Now — DevStage.io · AI Portal Engineer (Backstage & DevEx)

I turn Backstage into an **AI developer portal for enterprise clients** — and I
deliver Backstage as a service: custom plugins, catalog processors, TechDocs, and
onboarding automation. Recent work:

- **Backstage chatbot** — a chat interface wired to Backstage's MCP and other
  sources, answering over the Software Catalog, TechDocs, and Scaffolder.
- **Catalog onboarding at scale** — onboard repos into the catalog by generating
  `catalog-info.yaml` and opening PRs (or writing straight to the repo).

**Open-source Backstage examples (DevStage):**

- [**catalog-coverage plugin**](https://github.com/DevStageIO/devstage-backstage-plugins/tree/main/workspaces/catalog-coverage) — onboards repos into the catalog at scale. AI reads each repo's README and proposes a starting `catalog-info.yaml`, which you can edit in the UI and send to the owning team as a PR — so you arrive with a concrete proposal to review, discuss, and merge together. Cuts onboarding mistakes.
- [**catalog processor module**](https://github.com/DevStageIO/catalog-backend-module-example-processor) — processors extend how Backstage ingests information: they let you pull entities from non-standard sources (e.g. an API) and fill the catalog with them. A reference module showing how to read from a custom source and process it into the catalog.
- [**TechDocs cookbook**](https://github.com/DevStageIO/backstage-techdocs-demo) — TechDocs formatting & visualization examples.
